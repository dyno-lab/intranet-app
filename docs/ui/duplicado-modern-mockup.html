Referencias de comportamiento

Estado sin datos

Cuando los filtros no devuelvan resultados, esta referencia sustituye la tabla. Mantiene los filtros seleccionados, no muestra filas artificiales y ofrece una acción clara para ajustar filtros.

Adaptación móvil

  • Filtros apilados en una sola columna.
  • Acciones con wrap o ancho completo según espacio disponible.
  • Resumen dividido en bloques legibles.
  • Tabla con desplazamiento horizontal controlado.
  • Áreas táctiles amplias y foco visible.
