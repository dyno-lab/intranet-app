Estados secundarios

Sin criterios completos

La vista previa no se muestra hasta tener propuesta, periodo valido y residencial o Global.

Sin datos para este filtro

Las tablas y graficas conservan estructura, totales en cero y mensajes de ausencia cuando no hay informes de notas.

Periodo personalizado

  • Personalizado oculta Mes/Año.
  • Personalizado muestra Fecha inicial y Fecha final.
  • El filtro compara el primer dia del mes del informe contra el rango seleccionado.

PDF y rutas

  • La version imprimible actual usa /ui/reports/notas/pdf.
  • La descarga PDF individual no existe hoy como /ui/reports/notas/pdf/download; el boton queda como requisito de implementacion futura.
  • La descarga binaria debera proteger el formato actual y evaluar Chromium si se requiere paridad con la version imprimible.

Responsive

  • Filtros, resumen y vista previa pasan a una columna en pantallas estrechas.
  • Las acciones mantienen el orden aprobado: Vista previa, Descargar PDF, Descargar Excel y Versión imprimible.
  • Las tablas de edad, residencial y materia conservan desplazamiento horizontal controlado.
