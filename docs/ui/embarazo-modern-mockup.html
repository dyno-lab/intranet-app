Estados secundarios

Sin criterios completos

La vista previa no se muestra hasta tener propuesta, periodo valido y residencial o Global.

Sin datos para este filtro

La tabla conserva encabezados y muestra el mensaje actual cuando no hay registros para los criterios seleccionados.

Periodo personalizado

  • Personalizado oculta Mes/Año en el Centro de reportes.
  • Personalizado muestra Fecha inicial y Fecha final.
  • El filtro compara el primer dia del mes del informe contra el rango seleccionado.

PDF y descarga

  • La version imprimible conserva el formato establecido.
  • Descargar PDF queda como requisito de implementacion futura para este reporte.
  • La descarga futura debe preservar la misma apariencia de la version imprimible.

Responsive

  • Filtros, resumen y vista previa pasan a una columna en pantallas estrechas.
  • Las acciones mantienen el orden aprobado: Vista previa, Descargar PDF, Descargar Excel y Versión imprimible.
  • La tabla conserva su estructura actual y usa desplazamiento horizontal controlado.
